# UI V2 圆角双层血条

本轮只修复公共双层血条与矿石血条。参考 `ArtSource/UI/V2/References/Ref_DualHealthBar.png`；保留真实生命值接口、伤害和恢复机制，不修改角色、履带、关卡布局及其他业务 UI。

正式可编辑源为 `/Game/MineLearning/UI/V2` 的 UMG 与 UI 材质。采用圆角胶囊内槽、细金属包边、暗色承托、柔和投影、玻璃纵向明暗层次，以及跟随当前血量末端的浅色渐变高光。绿／黄／红分别表达健康、警戒、危险；暗红层表达近期损失，短暂停留后平滑追赶当前值。

边框与填充共用同一坐标和轮廓，避免九宫格图片留白、切片与覆盖顺序造成错位。尺寸以游戏实际可读性为准，不能用放大矩形色块替代设计。

验收：满血、半血、低血、空血均有正确圆角和包边；扣血即时变化、红色残留平滑消退、恢复正确；在矿区实际视角检查细节、比例与相邻血条。所有 UE 资产操作通过 MCP，截图只作临时验收材料。

## 当前落地

- `M_UIv2_HealthGauge` 以同一圆角轮廓绘制金属外壳、内槽、玻璃填充、渐变端点和阴影；调色与受击残留时间通过材质参数配置。
- `WBP_UIv2_DualHealthBar.UpdateHealth` 接收生命值，仅在比例改变或首次初始化时刷新动画，防止重复事件擦掉残留层；数值标签每次更新。无 Tick、轮询或循环 Delay。
- 残留层默认停留 0.25 秒，再用 0.75 秒平滑收缩；连续扣血从当前残留位置继续，回血立即同步。表现时钟与 Slate UI 材质保持一致。
- 矿石控件复用公共组件，显示区域 320×72。旧视觉树折叠保留，旧显示执行链已被新版替代，便于检查迁移。
- 在矿区 PIE 和全屏视口检查了满血、240/600 警戒、120/600 危险及 600→300→420 扣血恢复。慢放检查了残留层出现与消退，随后恢复正常参数；蓝图严格编译无警告。验收截图在 `Saved` 临时目录，不作为美术源提交。
