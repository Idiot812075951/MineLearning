# Visual Match Checklist — Modeling

Upstream source: [visual-match-checklist.md at 8f778d2](https://github.com/arjun988/blender-skills/blob/8f778d2405a214b508d4c7d80742be8e43acdd52/.claude/skills/references/visual-match-checklist.md).

Rate only dimensions in the current modeling scope:

- Reference/view is comparable and not mirrored or from the wrong side.
- Primary silhouette and accepted proportions remain correct.
- Target armor mass, thickness, overlap, and articulation clearance read correctly.
- Secondary breaks follow the reference or a functional construction seam.
- Edge radii are intentional at gameplay distance; no global bevel look.
- No unsupported screws, vents, panels, or mechanisms were added.
- No new intersections, shading failures, open-boundary damage, or modifier-order regressions.
- Protected armature, weights, shape keys, UVs, material slots, parenting, pivots, and animation data are unchanged.

Do not use the upstream numeric pass threshold as automatic approval. The current Asset Brief and user review define acceptance.
