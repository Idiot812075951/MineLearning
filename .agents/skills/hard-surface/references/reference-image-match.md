# Reference Image Match — Geometry Scope

Upstream source: [reference-image-match.md at 8f778d2](https://github.com/arjun988/blender-skills/blob/8f778d2405a214b508d4c7d80742be8e43acdd52/.claude/skills/references/reference-image-match.md).

Read when a modeling task asks to match supplied concept art or renders.

1. Identify the authoritative reference and what is already accepted in the current asset.
2. Compare camera/view, silhouette, major mass ratios, thickness, overlap, negative space, and distinctive functional forms before micro-detail.
3. Separate geometry mismatch from camera, pose, material, lighting, and render mismatch. Do not edit those other domains unless authorized.
4. On a locked production character, preserve accepted head, chest, and whole-body proportions. Restrict the current experiment to the named isolated copy.
5. Capture comparable views after meaningful stages and keep a short prioritized gap list. Iteration count follows the task and stop conditions, not a fixed pass count.

Reference matching is not permission to rebuild an existing asset, create unsupported features, or alter protected rig/animation data.
