# MineLearning 机械 Animation 规则

仅在任务涉及 Action、关键帧、循环、机械动作、Root Motion、NLA 或动画导出时读取。

## 数据保护

- 修改前记录 Action 名称、Slot/绑定对象、帧范围、FPS、Marker、NLA、当前活动 Action 和当前帧。
- 默认不重命名、删除、覆盖或合并现有 Action；新动作使用 Brief 指定的名称与帧范围。
- 不在未确认 Auto Key、选择集、当前模式或活动对象时写关键帧。
- 不用修改 Skeleton、Rest Pose、Vertex Group 或功能结构位置来掩盖动画问题，除非任务同时明确授权 Rig 修改。

## 动作原则

- 动作首先表达功能：启动、工作循环、停止、移动、采集、交付、装填或状态反馈必须可读。
- 机械动作保持重量感、明确停顿和合理加减速；避免无意义的全身漂浮、软体摆动或高频抖动。
- 旋转件、伸缩件和爪指应遵循 Pivot、局部轴和机械范围，不得穿插或脱节。
- 循环动作检查首尾姿态、速度与切线连续性；非循环动作保留清楚的起始、主要动作和收束阶段。
- Root Motion 只在玩法与 Brief 明确需要时使用；否则 Root 保持稳定，由运行时移动系统负责位移。

## 验证

- 对每个受影响 Action 检查首帧、中间关键姿态和末帧；循环动作额外检查跨首尾播放。
- 求值所有相关对象，检查 Transform 有效、关节无跳变、非目标部件未被误写。
- 确认 Action 名称、数量、帧范围、Slot/NLA 和关键帧未发生任务外变化。
- 恢复原活动 Action、当前帧和播放状态，再保存阶段版本。
- 报告修改过的 Action、帧范围、关键姿态、循环/Root Motion 决策和未解决风险。

需要导出或重导入 UE 时，继续读取 `ue-export-checklist.md`。
