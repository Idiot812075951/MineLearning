# 模块化矿石玩法资产 Skill

## 1. 目标

制作能够直接服务挖矿玩法的模块化矿石资产，而不是单一、不可交互的展示模型。

资产必须能够支持或预留以下表现：

- 矿体受到攻击；
- 表层矿块被敲落；
- 掉落可拾取的矿石碎块；
- 矿体随生命值进入破损阶段；
- 后续接入裂纹材质、命中特效、物理掉落或局部形变。

优先采用稳定、可控、容易程序接入的方案。不要为了“高级”而默认使用实时布尔、复杂破碎、雕刻高模或难以维护的程序化系统。

---

## 2. 核心原则

### 2.1 玩法优先

每个建模决定都必须回答至少一个问题：

- 玩家为什么能看出这里可以挖？
- 被攻击后哪部分会发生变化？
- 哪个对象可以隐藏、脱落或生成掉落物？
- 程序如何独立控制这些部分？
- 同一套模块能否组合出多个矿点？

无法回答这些问题的细节属于低优先级。

### 2.2 模块优先

标准矿点由以下模块组成：

1. **Base Rock**：矿点主体，承载碰撞、血量和主要轮廓；
2. **Surface Ore Chunk**：附着在主体表面的可脱落矿块；
3. **Drop Chunk**：受击后生成或掉落的独立拾取碎块；
4. **Damage Stage**：可选的破损阶段模型或材质表现。

除非任务明确要求，否则禁止把所有内容合并成一个无法拆分的网格。

### 2.3 Q 版不等于球形

“圆润”表示适度软化块面边缘，不表示把资产整体做成：

- 球体；
- 椭球体；
- 鹅卵石；
- 鹅蛋；
- 光滑陶瓷；
- 规则石墩。

矿石仍应具有明显的岩石切面、不对称轮廓和受力破碎感。

## 3. 标准资产结构

推荐对象与 UE 资产命名：

```text
SM_Ore_Iron_Base_A
SM_Ore_Iron_SurfaceChunk_A_01
SM_Ore_Iron_SurfaceChunk_A_02
SM_Ore_Iron_SurfaceChunk_A_03
SM_Ore_Iron_SurfaceChunk_A_04
SM_Ore_Iron_DropChunk_A_01
SM_Ore_Iron_DropChunk_A_02
```

Blender Collection 推荐结构：

```text
COL_Ore_Iron_A
├─ GEO_EXPORT
│  ├─ SM_Ore_Iron_Base_A
│  ├─ SM_Ore_Iron_SurfaceChunk_A_01
│  ├─ SM_Ore_Iron_SurfaceChunk_A_02
│  ├─ SM_Ore_Iron_SurfaceChunk_A_03
│  ├─ SM_Ore_Iron_SurfaceChunk_A_04
│  ├─ SM_Ore_Iron_DropChunk_A_01
│  └─ SM_Ore_Iron_DropChunk_A_02
├─ LAYOUT_PREVIEW
│  └─ 组合预览实例
└─ PREVIEW_ONLY
   ├─ Camera
   ├─ Key Light
   ├─ Fill Light
   ├─ Rim Light
   └─ Ground
```

`PREVIEW_ONLY` 中的相机、灯光和地面不得作为游戏模型导出。

## 4. 造型规范

### 4.1 Base Rock

基础石体必须满足：

- 主轮廓不对称；
- 从正面斜上方能够看到 6～12 个清晰的大块面；
- 至少有 2 个明显的高低变化或方向变化；
- 底部能够稳定落地；
- 不做纯球、纯柱、纯方块或被平滑后的默认几何体；
- 边缘可适度倒圆，但必须保留块面；
- 轮廓在游戏常用距离仍可辨识。

推荐轮廓层级：

- **60% 大轮廓**：整体形状和重心；
- **30% 中轮廓**：切面、崩角、凹凸；
- **10% 小轮廓**：少量裂口和矿物接触细节。

禁止使用高频噪声替代真实造型。

### 4.2 Surface Ore Chunk

表层矿块必须是独立对象，并满足：

- 看起来从岩石内部生长或暴露出来，而不是贴纸、按钮或虫子；
- 约 25%～45% 的体积可嵌入基础石体，确保视觉连接；
- 每块具有明确、可识别的外露轮廓；
- 至少包含两类形态：
  - 块状金属结晶；
  - 沿切面或裂隙延伸的粗矿脉；
- 尺寸与形状不能完全一致；
- 可想象为受到锤击后沿接触区域断裂；
- 不允许全部做成圆形斑点或细小黑疙瘩。

建议一个中型矿点布置 3～6 块表层矿块。

### 4.3 Drop Chunk

掉落碎块必须：

- 与表层矿块属于同一视觉家族；
- 轮廓比真实碎屑更清楚，便于玩家识别奖励；
- 不直接照搬过大的表层矿块；
- 原点位于近似质心，便于物理旋转；
- 可在地面滚动，但不应接近球形；
- 单个碎块不依赖复杂材质才能辨认。

## 5. 材质规范

### 5.1 岩石主体

建议范围：

- Base Color：暖灰、灰褐、暗红褐；
- Metallic：0；
- Roughness：0.65～0.9；
- 避免过白、奶油色和陶瓷感；
- 明暗变化优先由块面和灯光产生，不依赖密集噪声。

### 5.2 铁矿部分

建议范围：

- Base Color：深铁灰、枪灰、略带暗红氧化色；
- Metallic：0.75～1.0；
- Roughness：0.3～0.55；
- 必须具有清晰但不过度镜面的高光；
- 可增加少量非金属氧化边缘，但不要把整块做成锈铁。

矿物区域应占主要可见面的约 15%～30%。过少看不出是矿点，过多会像金属球。

### 5.3 材质数量

- Base Rock：优先 1 个材质；
- 所有 Iron Surface Chunk：优先复用 1 个铁矿材质；
- Drop Chunk：优先复用铁矿材质；
- 禁止为每个小块创建重复材质。

---

## 6. 尺寸与复杂度

尺寸以任务 Brief 为准。默认中型矿点参考：

- 宽：140～190 cm；
- 深：110～160 cm；
- 高：90～140 cm。

建议三角面预算：

- Base Rock：800～2,500；
- 单个 Surface Ore Chunk：150～600；
- 单个 Drop Chunk：100～400；
- 完整中型组合：通常不超过 6,000～7,000。

禁止：

- 为简单轮廓保留上万三角面；
- 使用细分曲面制造无意义的光滑；
- 依赖雕刻高模解决基础轮廓问题。

---

## 7. Pivot、Transform 与对象独立性

### Base Rock

- Pivot 位于底部中心；
- 最低点接近本地 Z=0；
- Location / Rotation 归零；
- Scale 应用为 `(1,1,1)`。

### Surface Ore Chunk

- 必须是独立对象；
- 不与 Base Rock 合并或焊接；
- Origin 放在自身近似质心，便于脱落后的物理运动；
- 在组合预览中的相对位置必须保留；
- 不得通过父子层级掩盖未应用的缩放。

### Drop Chunk

- Origin 位于近似质心；
- 应用 Transform；
- 法线朝外；
- 不得存在孤立顶点、重复面或明显非流形错误。

## 8. 玩法接入建议

推荐 UE 结构：

```text
BP_MineableOre
├─ BaseRockComponent
├─ SurfaceChunkComponent_01
├─ SurfaceChunkComponent_02
├─ SurfaceChunkComponent_03
└─ SurfaceChunkComponent_04
```

受击流程建议：

1. 命中矿体；
2. 播放命中特效和声音；
3. 根据命中位置或阶段选中一个 Surface Chunk；
4. 隐藏或移除该 Surface Chunk；
5. 生成对应 Drop Chunk；
6. Drop Chunk 开启短暂物理；
7. 主矿体血量下降；
8. 达到阈值后切换破损阶段或更新裂纹材质；
9. 最终矿体被采空。

资产只负责提供可控制的部件，不在 Blender 中实现业务逻辑。

---

## 9. 破损阶段策略

优先级从简单到复杂：

1. **独立表层矿块隐藏/掉落**；
2. **裂纹材质参数随血量变化**；
3. **Stage A / B / C 静态模型切换**；
4. **预制碎裂或 Geometry Collection**；
5. **实时布尔或动态网格切割**。

默认从 1～3 开始。没有明确玩法收益时，不直接选择 4～5。

---

## 10. 美术验收标准

模型必须通过以下检查：

### 轮廓

- 一眼看出是可挖的矿点，而不是蛋、土墩或普通装饰石；
- 正面斜上方和侧面轮廓均有明显差异；
- 基础石体不依赖矿块也成立。

### 矿物关系

- 矿物看起来嵌入、贯穿或暴露于岩石；
- 不能像贴纸、圆点或随意粘上的黑块；
- 至少一块矿物形成明显视觉焦点。

### 玩法关系

- Base Rock、Surface Chunk、Drop Chunk 均可独立选择；
- Surface Chunk 可以独立隐藏或导出；
- Drop Chunk 适合物理掉落；
- 组合结构能够清楚说明“哪部分会被敲下来”。

### 技术检查

- 命名正确；
- Transform 已应用；
- Pivot 合理；
- 法线正确；
- 无重复面、孤立顶点和明显非流形；
- 面数处于预算；
- 灯光、相机、地面不进入导出集合。

---

## 11. 禁止项

禁止提交以下结果：

- 光滑鹅蛋上贴几块不同颜色区域；
- 规则石墩上粘几个小黑点；
- 所有矿物和岩石焊成不可拆分的单网格；
- 仅靠颜色区分矿物，不提供可脱落几何体；
- 表层矿块全部同形、同尺寸、等距分布；
- 过度细分但轮廓仍然简单；
- 为了截图效果使用无法在 UE 中复现的复杂材质；
- 未经要求操作 UE、修改玩法代码或提交 Git；
- 覆盖现有机器人或其他 Blender 源文件。

---

## 12. 每轮交付报告

完成后必须简要报告：

1. 源文件路径；
2. 对象列表；
3. Base Rock、Surface Chunk、Drop Chunk 的对应关系；
4. 每个对象的三角面数和尺寸；
5. 材质列表及复用关系；
6. Pivot 与 Transform 检查结果；
7. 哪些对象可独立脱落；
8. 整体组合图；
9. 所有模块分开展示图；
10. 未完成项和风险。

报告应简短、可核查，不写大段自我评价。
