# 红莲圣天八极式参考图库索引

## 使用优先级

1. **动画形态 Source of Truth**：官网设定图 `official_r2_mecha_01c.jpg`，保留的 TURN 18 画面 `official_r2_turn18_d.jpg`、`anime_r2_turn18_ruru18-04.jpg`、`anime_r2_turn18_ruru18-05.jpg`、`anime_r2_turn18_ruru18-07.jpg`、`anime_r2_turn18_ruru18-08.jpg`，以及用户提供的 `ref_09_anime_wing_front.png`、`ref_23_anime_palm_launch_frame.png`。
2. **三维结构补充**：商品/模型图片只用于判断头胸层叠、肩腕连接、指节、翼根与背面结构，不覆盖动画比例和主轮廓。
3. **姿势与功能补充**：游戏画面、宣传图与 CG 用于 Palm、Arm Launch、飞行和攻击构图，不作为静态比例唯一依据。
