# Robot Center 第二轮优化施工清单

> 基于当前 Blockout 继续施工。
> 本轮目标不是“加细节”，而是把当前的 **平台 + 几个设备** 提升成真正的 **Robot Center 主设施**。

## 本轮核心目标

只解决 4 件事：

* [ ] 中央主体更像“中心”
* [ ] 左侧更像“机器人售卖区”
* [ ] 右侧更像“玩家幻化区”
* [ ] 整个设施形成明确的高 / 中 / 低层级

本轮 **禁止进入螺丝、按钮、小管线等细节施工**。

---

# P1：强化 Main Frame

当前最大问题之一：

> 顶部横梁像招牌架，建筑级体量不足。

修改：

* [ ] `SM_RobotCenter_MainFrame` 顶部横梁厚度增加约 **20%~30%**
* [ ] 左右主支柱横截面增加约 **15%~25%**
* [ ] 支柱底部增加更厚的机械基座
* [ ] 顶梁两端不要只用小黄色方块结束，增加一个较完整的端部机械包边
* [ ] 保持前方完全开放，不增加墙
* [ ] Main Frame 仍然保持“宽 > 高”

目标轮廓：

```text
现在：

───────细横梁───────
│                   │


调整后：

█████████████████████
██                 ██
██                 ██
```

不要真的做得这么粗，只表达：

> **主框架必须有重量。**

---

# P2：Main Core 必须成为视觉中心

当前中央 Core 太像普通终端。

目标：

> 它应该是整个 Robot Center 的主控机 / 能源核心。

针对：

`SM_RobotCenter_MainCore`

执行：

* [ ] 整体宽度增加约 **25%~35%**
* [ ] 高度增加约 **15%~25%**
* [ ] 厚度增加约 **20%**
* [ ] 整体略微向玩家方向移动
* [ ] 不要完全缩在 Main Frame 后方
* [ ] 底部增加一个明显的深灰机械基座
* [ ] 顶部保留一块黄色外壳
* [ ] 正面只保留 **一个主要显示区 / 核心区**
* [ ] 正面屏幕面积不要占整个主机

结构推荐：

```text
      顶部黄色外壳
   ┌───────────────┐
   │               │
   │   主显示区     │
   │      ◉         │
   │               │
   ├───────────────┤
   │ 深灰机械底座   │
   └───────────────┘
```

不要增加多块屏幕。

# P3：Main Core 和顶梁形成一套结构

现在：

```text
顶梁

    空

中央主机
```

两者联系偏弱。

修改：

* [ ] Main Core 上方增加 **2 个粗短机械支撑**
* [ ] 支撑连接 Main Core 和 Main Frame
* [ ] 不做细管
* [ ] 支撑保持左右对称或近似对称
* [ ] 数量最多 2 个

最终形成：

```text
████████ MAIN FRAME ████████
          ╲     ╱
           ╲   ╱
        ┌─────────┐
        │Main Core│
        └─────────┘
```

视觉上直接告诉玩家：

> Main Core 是整个建筑的一部分，不是后面摆了个柜子。

不要推翻。


不要做六根机械臂。

## 本轮最重要的一句话

> **不要通过“增加零件”让 Robot Center 更丰富，而要通过“强化主次、体量和功能结构”让它更完整。**

本轮完成之后，应该从：

> “平台上摆了一个商店和一个扫描门”

提升为：

> **“这是一整套 Robot Center，左侧负责机器人部署，右侧负责玩家机体重构。”**
