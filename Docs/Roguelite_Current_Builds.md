# 肉鸽现有内容与构筑整理

核对日期：2026-10-03。范围：`L_WorldLayout_P01` 的现有玩法、C++ 与编辑器内实际 DataTable / DataAsset 配置。

本轮只读分析，不修改代码、配置或资产，也未重新运行玩家体验测试。下文“当前”来自代码与配置；“有趣”“值得优先拿”等属于设计判断，不是经过统计验证的强度结论。

## 1. 结论

目前已经形成“生产资源 → 付费抽升级 → 强化生产/战斗 → 挑战超级铁矿 → 获得永久解锁”的闭环。它更接近**带肉鸽构筑的矿区生产挑战**，而不是已经具备随机地图、敌人组合和多难度循环的完整肉鸽游戏。

真正可搭配的内容集中在 Gunner。其他单位并非不能吃 Buff，而是缺少能改变操作方式和决策的专属升级：

| 单位 | 当前可形成的玩法 | 完整程度 |
| --- | --- | --- |
| Gunner | 单发/三连发切换、移动命中叠层、特殊子弹、概率大弹夹、黄金武器 | 最高，已有几种打法差异 |
| OreBuddy | 钻采叠层、拾取触发加速、自动矿工与幻影协作 | 能形成效率组合，专属形态变化不足 |
| Carrier 搬运工 | 移动与装卸加速、拾取狂热、自动运输与幻影 | 有生产作用，但构筑主要是“更快” |
| 红莲 / Guren | 普攻压低血量、Q 处决、R 降临，攻速/施法速度分工 | 基础技能丰富，专属升级为零 |
| 人类 | 交互、选择身份、转换形态 | 没有普通攻击，不必强行做战斗构筑 |

建议优先补 OreBuddy、Carrier、红莲的行为型升级，而不是继续扩大 Gunner 的卡牌数量。具体候选与实施顺序见 [内容填充方案](Roguelite_Content_Expansion.md)。

## 2. 四种“升级”需要区分

| 系统 | 花费与入口 | 获得什么 | 是否跨局 |
| --- | --- | --- | --- |
| 永久天赋 | 通关天赋点；开局前研究 | 形态购买资格、卡牌出现资格、召唤师选择资格 | 是 |
| 召唤师身份 | 已解锁后开局免费选择 | 专属卡牌进入候选池的条件 | 默认选择会保存，本局锁定 |
| 局内升级卡 | 商店消耗仓库金币抽取 | 本局升级等级、常驻效果或触发能力 | 否 |
| 终端核心强化 | Tab 终端消耗金币 | 本局力量/敏捷/智力固定加成 | 否 |

“已解锁”不等于“已拥有能力”。氪金玩家身份不会免费发黄金 AK，复制人身份也不会直接生成幻影；仍要在局内付费抽到对应卡。

卡牌等级与 Buff 层数也是不同概念：刃舞最多购买 3 级；致命征服者只购买 1 次，战斗中再积累最多 8 层；漫游枪手只购买 1 次，临时层数无配置上限，但最终速度有上限。

### 永久天赋现状

实际配置有 **7 个节点**，每个 1 点，正常通关每次奖励 1 点。新档从零开始，全部研究共需 7 点；没有 GM 的情况下对应累计 7 次正常胜利。

| 节点 | 前置 | 解锁结果 |
| --- | --- | --- |
| 红莲资格 | 无 | 局内可以购买红莲形态，仍需 10 原矿 |
| 三连射 | 无 | 三连射卡可以进入卡池；还需本局购买 Gunner |
| 超级子弹 | 无 | 超级子弹卡可以进入卡池；还需本局购买 Gunner |
| 超级弹夹 | 永久节点“超级子弹” | 超级弹夹卡可以进入卡池；还需本局购买 Gunner |
| 搜集狂热者 | 无 | 开放拾取触发加速卡 |
| 氪金玩家 | 无 | 可以选择该召唤师 |
| 复制人 | 无 | 可以选择该召唤师 |

超级弹夹的前置是**永久研究前置**，不是“本局先抽到超级子弹”。本局可以先抽到超级弹夹。

存档保存点数、已研究节点、默认身份；正常开局锁定当局资格。GM 清档会删除该档并重开地图。现在的天赋树以内容许可为主，没有独立的永久数值成长分支，也没有已配置的高难度专属奖励树。

### 终端核心强化不是永久天赋

代码仍保留力量、敏捷、智力三项核心强化：每次 +5，各最多 3 级，价格分别为 2、4、6 金币。它们是本局的确定性购买，与随机卡牌共用经济。

这一点容易造成误解：玩家同时面对“天赋点研究”“金币买属性”“金币抽属性卡”。例如力量卡一次 +50，而终端力量一次 +5，数值量级差很大。两者是否都应该长期保留，需要明确各自价值，不能只因为旧功能还在就一直叠加入口。

## 3. 两个召唤师实际怎么用

| 身份 | 付费能力 | 当前打法 | 限制 |
| --- | --- | --- | --- |
| 氪金玩家 | 黄金 AK | 围绕 Gunner 的伤害、爆头与弹药组织构筑 | 其他形态没有身份专属收益；未抽到卡前与普通身份差别有限 |
| 复制人 | 复制人幻影 | 幻化为受支持形态，获得临时 AI 帮手，参与挖矿、搬运或射击 | 同时最多一个，30 秒寿命；红莲和人类不生成幻影 |

复制人的幻影不是“再复制一套背包和进度”：它是相同单位类型的新 AI，按当前构筑装配适用升级，并额外获得移速、攻速、施法速度各 +50%。

取得幻影卡时，如果当前形态支持 AI，会立即生成；之后成功幻化到受支持形态也会生成/替换。没有在寿命结束后自动持续补充的规则。回到不支持 AI 的形态会清理已有幻影。

有趣之处是“这 30 秒让什么单位帮忙”：缺产出用 OreBuddy，缺运输用 Carrier，需要输出时用 Gunner。局限是换形也可能成为反复刷新幻影的操作负担，后续应实测收益与操作频率，不能把频繁往返换形当成默认乐趣。

## 4. 现有 12 张卡牌完整清单

所有卡均需局内付费抽取。除特别注明外，当前配置为作用于符合单位类型的己方单位，包括受装配的自动单位与幻影；并不只强化玩家当前控制的角色。临时触发状态由每个单位独立持有。

| 卡牌 / ID | 入池条件 | 购买上限 | 实际效果与作用对象 |
| --- | --- | --- | --- |
| 刃舞 / `AttackHaste50` | 基础开放 | 3 | 每级攻速 +50%；通用，有对应动作的单位才受益 |
| 疾风步 / `MoveHaste50` | 基础开放 | 3 | 每级移速 +50%；地面移动与冲刺受益 |
| 灵光一闪 / `CastHaste100` | 基础开放 | 1 | 施法速度 +100%；包括 Gunner 换弹、OreBuddy 拾取、红莲技能 |
| 力量强化 / `Strength50` | 基础开放 | 3 | 每级力量 +50；按各技能力量系数转为伤害，不是伤害 +50 |
| 致命征服者 / `Conqueror` | 基础开放 | 1 | 普攻命中 +1 层，最多 8；每层普攻伤害、攻速各 +5%，满层普通攻击距离 +25% |
| 漫游枪手 / `Roamer` | 本局已购买 Gunner，无独立永久节点 | 1 | Gunner 移动命中时左右 +2、前后 +1；每层移速、攻速各 +5% |
| 搜集狂热者 / `Collector` | 研究对应节点 | 1 | OreBuddy / Carrier 成功拾取后 50% 概率移速、施法速度各 +50%，5 秒；再次触发刷新 |
| 三连射 / `TripleShot` | 对应天赋＋本局已购 Gunner | 1 | 右键切换单发/三连发；三连发点按左键射三发，逐发射速 ×2，长按不重复；爆头与黄金爆头概率减半 |
| 超级子弹 / `SuperRound` | 对应天赋＋本局已购 Gunner | 1 | 每第 10 发实际发出的子弹伤害 ×2、命中特效尺寸 ×2；不是第 10 次命中 |
| 超级弹夹 / `SuperMagazine` | 对应天赋＋本局已购 Gunner | 1 | 换弹完成时 50% 概率获得两倍基础容量，20 → 40；不会递归翻倍 |
| 黄金 AK / `GoldenAK` | 氪金玩家身份＋本局已购 Gunner | 1 | Gunner 普攻伤害 +50%，黄金爆头概率 +5 个百分点，武器变金色 |
| 复制人幻影 / `Phantom` | 复制人身份 | 1 | 开放上述幻影生成能力，本身不是一份直接加在玩家身上的三速 Buff |

补充边界：

- 致命征服者是普攻伤害加成，不是所有技能攻击力，不附带吸血。红莲 Q/R 不因施法而给它叠层。
- 致命征服者每次命中刷新 5 秒；超时先掉一层，之后每 0.5 秒掉一层。未命中不直接清空；离开满层后射程奖励立即消失。
- 漫游枪手只有符合移动条件的命中才加层、刷新 3 秒；到期逐层以 0.5 秒间隔衰减。任何未命中直接清零，包括空枪射线、超距和 AI 失手。斜向移动按主要方向判定。
- AI Gunner 持有漫游枪手时，每次攻击有 10% 概率失手，零层时也有该概率；玩家没有这项随机失手。AI 正常命中不代表能忽略距离、失效目标等约束。
- 当前五张基础卡是刃舞、疾风步、灵光一闪、力量强化、致命征服者。没有研究也能开始组合。
- 两个身份专属卡不能在正常同一局同时获得。天赋全开、形态已购时，单局最多有 11 种不同卡可用，并非全部 12 种。

## 5. 三速与伤害：哪些搭配真正有效

| 单位 / 行为 | 攻速 | 施法速度 | 移速 | 容易误解之处 |
| --- | --- | --- | --- | --- |
| Gunner 开火 / R 换弹 | 开火节奏及动画 | 换弹动作 | 移动 | 攻速不直接减少换弹；射线命中还要在攻击距离内 |
| OreBuddy 左键钻采 / R 拾取 | 钻采节奏及动画 | 拾取过程 | 赶路和运输 | 狂热搜集者不直接提高钻采攻速 |
| Carrier 左键装卸 | 装卸动作 | 同一个装卸动作 | 运输 | 同一动作按 `1 + 攻速加成 + 施法加成` 合并，不能把两者倍率再相乘 |
| 红莲左键 / Q、R | 近战连击 | 技能阶段和表现时序 | 地面移动 | 施法加速不是冷却缩减；不等于提高伤害/处决线 |
| 人类 | 无对应普攻 | 无上述战斗技能 | 地面移动 | 出现状态不等于所有属性都有实际用途 |

最终地面速度上限为 1000 cm/s，普通攻击节奏上限为每秒 5 次。它们是当前 UE 项目的单位与限制，不应理解为与其他游戏完全同一套手感。不同角色基础间隔不同，攻速 +50% 表示在原节奏上加速，而不是统一变成每秒 1.5 次。

同类百分比相加：两级刃舞是 +100% 攻速；黄金 AK +50% 普攻伤害与满层征服者 +40% 合起来是 +90%，不是两次独立相乘。特殊子弹的本发 ×2 属于另一环节。

按当前 Combat DataAsset、未计其他加成，每次基础普攻为：OreBuddy 40、红莲 51、Gunner 32.5。力量 +50 都通过 0.3 的力量系数增加 15 点普攻伤害。因此同一张力量卡，相对增幅约为 37.5%、29.4%、46.2%；还需结合各自节奏、技能与暴击评估，不能只看面板数字。

Carrier 没有伤害技能，力量/普攻伤害加成几乎没有直接工作收益；但它的成功装卸被接入普通攻击结算事实，因此致命征服者能提供装卸攻速与满层交互距离，伤害部分没有用途。这是现有语义妥协，也解释了为什么“通用卡”对它不一定通用。

## 6. 站在玩家角度，当前怎么组更有趣

下面是抽取优先级，不是保证能买到的固定配方。第一张核心卡没出现时，应按已抽到的内容调整，而不是把钱全赌在缺失卡上。

### A. Gunner：移动压枪流

- 核心：漫游枪手＋致命征服者；补强：刃舞、超级弹夹、灵光一闪。
- 操作：以单发长按为主要输出，左右移动积层，控制上扬与横向后坐力；距离不够就先走近，再开枪。
- 乐趣：移动、瞄准、持续命中相互促进，层数与红色狂热效果给出反馈。
- 代价：空一枪即丢失漫游层数；高射速也更快消耗弹药并放大控枪压力。不要只追求面板攻速。
- 适合用较大的矿物目标熟悉手感，但固定目标上的轻松叠层不能证明面对动态目标也平衡。

### B. Gunner：点射爆发流

- 核心：三连射＋超级子弹；补强：黄金 AK 或复制人幻影、力量强化、超级弹夹。
- 操作：短点三连发，观察弹药提示，把第 10 发附近的爆发尽量留给重要目标；远处难压枪时切回单发。
- 乐趣：同一把枪有节奏选择，不必一直按住左键。
- 代价：三连发降低爆头概率，且仍受射速上限。黄金 AK 不是与三连发毫无取舍的绝对最优组合；临近射速上限时，模式差异也会缩小。

### C. OreBuddy：钻采—拾取周转流

- 核心：刃舞＋致命征服者；补强：搜集狂热者、疾风步、灵光一闪；身份可选复制人。
- 操作：先连贯钻采积层，再拾取产物，利用狂热窗口赶路或完成下一次拾取，让自动搬运接手长距离运输。
- 乐趣：不只是站桩挖得快，而是在钻采、收集、交付之间寻找瓶颈。
- 代价：改去拾取/赶路后，钻采叠层可能衰减；5 秒狂热也未必覆盖长途。缺运输时继续堆钻速只会让地面产物堆积。

### D. Carrier：快递周转流

- 核心：疾风步＋灵光一闪＋搜集狂热者；补强：刃舞；复制人提供临时第二名搬运工。
- 操作：选短、顺路、有真实需求的线路，提高装卸与运输周转，不盲目抢走自动单位已预留的货物。
- 乐趣：缓解产线堵塞，让仓库金币增长更顺畅，支持本局其他形态构筑。
- 代价：当前货舱和工作形态没有可抽取的变化，路线优化的深度大于卡牌构筑深度。移动到上限后，更多移速不再解决问题。

### E. 红莲：压血线—处决流

- 核心：灵光一闪；按习惯补刃舞、力量强化、致命征服者。
- 操作：普攻处理未进入处决条件的目标，Q 接符合条件的可抓取目标，R 利用既有多目标降临能力。
- 乐趣：普攻和技能分工明确，动画反馈强；在当前内容里，它更像“技能玩法丰富、升级玩法不足”。
- 代价：Q 受可抓取/处决资格限制，R 也有自身目标契约；不能把所有对象都当作无条件处决目标。增加攻击距离只影响普攻，不扩大 Q/R 搜索范围。
- 两个现有召唤师都没有直接提供红莲专属能力；复制人也不能生成红莲 AI。可以为生产阶段选复制人，但不是红莲专属构筑。

### F. 队伍生产流：先让自动生产滚起来

- 先判断生产短板，再购买自动 OreBuddy / Carrier 与共享升级；玩家负责缺失环节或战斗。
- 通用速度卡与搜集狂热者会同时服务多个适用单位，价值可能高于单个角色面板所体现的价值。
- 这条路线最能体现挖矿项目特色，但要比较真实吞吐量：机器人在等待订单、找路或等待设备时，提高动作速度不一定增加产出。

## 7. 经济和内容结构的主要问题

1. **构筑成形成本偏高的风险。** 抽取依次为 4、8、12、16…金币，前三次共 24、前五次共 60。召唤 Boss 默认另需 20 金币＋12 铁锭，金币还要买机器人和终端强化。应实测正常一局能抽几次，再决定填多少需要三四张卡配合的组合。
2. **永久解锁可能稀释目标卡。** 当前所有卡权重均为 1；没有按当前打法保证候选，也没有重抽/流派选择配置。若所有条件满足，特定未满级卡在 11 种等权候选中的首轮出现率为 3/11，约 27.3%。这是条件概率，不是整局必定获得的概率。
3. **买过形态即可能混入相关卡。** Gunner 卡检查的是本局已购买 Gunner，而不是此刻是否控制 Gunner。玩家转玩红莲后仍可能抽到子弹卡；解锁本身不应成为“越研究越难玩到目标构筑”的惩罚。
4. **永久进度很快见底。** 7 点即可全部研究，继续通关缺少新的内容解锁目标；但用大量 +1% 永久属性延长时间，只会把重复劳动伪装成深度。
5. **过大的测试数值压缩选择。** 常驻 +50% 攻速、+100% 施法已经很强。新增“条件触发 +10%”很难让玩家感到值得选；先看时间与行为收益，再做正式平衡。
6. **共用单位范围缺少取舍。** 当前升级几乎全部覆盖己方适用单位，容易一起累积成同一种全能构筑；缺少真正的工作方式或技能变化。
7. **目标本身变化不多。** 如果始终是固定产线与同类矿石，只增加 Buff 会延长列表，却未必增加新的决策。后续需要少量能检验不同构筑的矿物/订单挑战。

另有一个本轮只记录、不修改的提示遗留：`DemoRunComponent.cpp` 的开局反馈仍写“Q 钻采”，实际绑定、技能栏与引导已改为左键。旧实现说明中的部分早期条目也未覆盖后来增加的卡牌，统计应以当前 DT 为准。

## 8. 现有框架能承载什么，不能直接承载什么

| 类型 | 当前能力 |
| --- | --- |
| 固定/百分比属性、普攻伤害、三速、普通攻击距离 | 已有配置字段；能新增 DA＋升级行 |
| 拾取后概率限时属性 Buff | 已有真实拾取事件接线，可配置同类效果 |
| 普攻命中叠层、移动条件、满层奖励、超时掉层、失手清层 | 已有行为实例，可配置变体 |
| 每 N 发特殊子弹、换弹概率容量、三连发模式 | 已有武器行为，不能直接当作任意单位的第 N 次攻击 |
| 新召唤师名字、解锁节点、专属卡资格 | 已有 DT；身份本身不会自动赠送效果 |
| 搬运容量、技能范围/目标数、特定技能伤害修正 | 不是现有通用 Modifier 字段，需要对应能力支持 |
| 普攻第三击、交付完成、处决成功、按目标标记 | 没有一套可直接配置的完整通用规则，需要补真实业务事件/状态 |
| 冷却、护盾、吸血、穿透、范围伤害、技能替换/觉醒 | 不能靠填一个事件名凭空实现，需要新增明确机制 |

底层效果、战斗与武器状态已经具备复用基础；“再填几张表就能做所有玩法”仍不成立。内容扩展应围绕真实动作增加少量可复用行为，而不是把每张卡写成角色类里的名字判断。
